# Intel-AI Backend

Modular FastAPI backend boilerplate.

Each feature is a self-contained subproject package directly under
`src/app/<name>/` (its own `router.py`, `schemas.py`, `service.py`, `models.py`)
and is mounted by the aggregator in `src/app/api/router.py`. This keeps parallel
development conflict-free: adding a subproject touches only its own folder plus
one registration line.

## Quick start

```bash
uv sync --extra dev          # install deps
uv run uvicorn app.main:app --reload --app-dir src
uv run pytest                # run tests
uv run ruff check .          # lint
```

## Database & migrations (Alembic)

Configuration lives in `core/config.py` (`DATABASE_URL`, async `asyncpg`
driver — copy `.env.example` to `.env`). Migrations are managed with Alembic;
`alembic/env.py` reads the URL from settings and autodetects every subproject's
models via `import_domain_models()`.

```bash
make migration m="add users table"   # autogenerate a revision (review it!)
make migrate                         # uv run alembic upgrade head
uv run alembic downgrade -1          # roll back the last migration
uv run alembic current               # show current DB revision
uv run alembic history --verbose     # list revisions
```

Always review autogenerated revisions in `alembic/versions/` before applying —
renames, type changes, and data migrations often need manual edits. `init_db()`
(`create_all`) is for dev/test only; use migrations for production schema
changes. See `docs/backend.md` for the full guide.

See the repository root `README.md` and `docs/` for full guidelines.
